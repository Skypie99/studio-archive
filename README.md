# The Studio Archive

A public, view-only edition of SkyPi Studio's art archive: 67 artworks shown in the order they were made, and a catalogue of 117 art supplies and colours across ink, graphite, watercolour, charcoal, conté and more.

**View it:** [archive.skypistudio.com](https://archive.skypistudio.com)

## What this is

- **View-only.** A static edition for looking, not a tool. There are no accounts, uploads or editing; you browse the artworks and the supplies catalogue.
- **Personal and historical.** It documents one artist's practice over time: studies, plein-air pieces, and the materials behind them. This edition was published in September 2026 and is not continuously updated.
- **Part of SkyPi Studio.** The main site is [skypistudio.com](https://skypistudio.com).

## How it's built

A single self-contained `index.html` (inline CSS, JavaScript and catalogue data) served by GitHub Pages from `main`. There is no build step and there are no dependencies.
